                                Advanced Features
                            
    
                            
    
                                
    
                                    
    
                                        SJIS Tunneling
                                    
    
                                    
    Map Western characters to unused Shift-JIS code points for in-game display
    
                                
    
                                
    
                                    
    
                                        GPT Dictionary
                                    
    
                                    
    Maintain consistent terminology with pre/post-translation enforcement
    
                                
    
                                
    
                                    
    
                                        Translation QA
                                    
    
                                    
    Automated quality checks for repeated words, untranslated text, and more
    
                                
    
                                
    
                                    
    
                                        Word Wrapping
                                    
    
                                    
    Automatic line breaking for monospace/proportional fonts

                                Pro Tips
                            
    
                            
    
                                
      
                                    
    • 
                                        
                                        Always backup original game files before patching
                                    
      • 
                                    
    • 
                                        
                                        Use GPT-4 for best translation quality, GPT-3.5 for speed
                                    
      • 
                                    
    • 
                                        
                                        Enable Translation QA to catch common issues automatically
                                    
      • 
                                    
    • 
                                        
                                        Use SJIS Tunneling if the game doesn't support Western characters
                                    
      • 
                                    
    • 
                                        
                                        Create a GPT Dictionary for character names and terminology consistency
